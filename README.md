## Overview

MediCynth is an AI-powered health platform with integrated features for healthcare diagnostics and personalized recommendations, focused on Indian datasets.

## Features

- **Skin Disease Diagnosis** — AI-based analysis for skin disease detection
- **MRI 3D Visualization** — 3D rendering and visualization of MRI scans
- **Medical Chatbot** — AI chatbot for health-related queries
- **Smart Diet Recommendations** — Personalized diet suggestions

## Problem

Healthcare gaps in India - limited specialist access, high diagnostic costs, and lack of preventive care tools.

## Solution

AI-powered platform targeting Indian population and local health datasets to make healthcare more accessible and affordable.

## Tech Stack

```
Backend: Python, TensorFlow, PyTorch, Opencv, deep learning
Frontend: Html css j.s
Database: PostgreSQL
Deployment: Vercel, Render
```
